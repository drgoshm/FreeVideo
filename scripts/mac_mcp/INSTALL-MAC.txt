FreeVideo MCP — установка на Mac

1. Запустите FreeVideo на Windows. Mac должен находиться в той же сети.
2. Распакуйте весь архив freevideo-mcp-macos.zip в любую папку на Mac.
3. Поместите access-key.txt и FreeVideo-LAN-CA.crt в ~/.config/freevideo/.
   Также установщик найдёт их рядом с собой или в ~/Downloads и скопирует
   в ~/.config/freevideo/. Уже существующие файлы не перезаписываются.
4. Откройте Install-FreeVideo-MCP.command двойным кликом.
   Если запуск из Finder недоступен, откройте Терминал и выполните:
     /bin/bash ~/Downloads/freevideo-mcp/Install-FreeVideo-MCP.command
   Укажите фактический путь, если архив распакован в другую папку.
5. Дождитесь сообщения Done и перезапустите Codex. В новом локальном чате:
   «Проверь подключение FreeVideo через MCP, генерацию пока не запускай».

Установщик загружает uv, Python 3.12, NumPy, Pillow и TOMLKit через интернет.
sudo, Homebrew и системный Python не нужны. Профили shell не меняются.
Файлы устанавливаются в ~/.local/share/freevideo-mcp/.
Каждая установка создаёт отдельную папку releases: прежний клиент остаётся
на месте, и ошибка установки не ломает его запуск.

Сначала проверяются запуск MCP, список инструментов и HTTPS-запрос к серверу
с проверкой сертификата. Генерация видео при проверке не запускается.
Только затем обновляется блок mcp_servers.freevideo в ~/.codex/config.toml
(либо в $CODEX_HOME/config.toml, если CODEX_HOME задан).
Другие MCP-серверы, настройки моделей, проектов и комментарии сохраняются.
В существующем блоке FreeVideo сохраняются пользовательские правила доступа
к инструментам, а параметры транспорта заменяются на текущий STDIO-клиент.

Резервная копия исходной конфигурации сохраняется рядом:
  config.toml.freevideo-backup-ДАТА-УНИКАЛЬНЫЙ_СУФФИКС
Перед записью проверяется корректность TOML и неизменность остальных настроек.
Запись атомарная. При некорректном TOML или изменении файла во время установки
установщик останавливается. При повторном запуске блок FreeVideo не дублируется.

Для отката закройте Codex и восстановите нужную резервную копию config.toml.
Это вернёт настройки целиком к моменту её создания. Если после установки были
другие изменения, перенесите из копии только прежний блок FreeVideo вручную.
Старые каталоги releases автоматически не удаляются.

Если адрес сервера изменился:
  /bin/bash /путь/Install-FreeVideo-MCP.command --url https://НОВЫЙ_АДРЕС:8443
Сертификат должен соответствовать новому адресу.

MCP автоматически предоставляет инструменты Codex, но не запускает постоянный
LLM-цикл. Для общения через Autopilot попросите Codex принимать сообщения
через freevideo_wait без ID и отвечать в текущую сессию до команды остановиться.
